## 📋 Какво трябва да направите сега

### Стъпка 1: Генериране на икони 🎨

1. Отворете файла `scripts/generate-icons.html` във вашия браузър
2. Иконите се генерират автоматично
3. Изтеглете трите файла:
   - icon.png
   - favicon.png
   - splash.png
4. Запазете ги в папката `assets/images/`

**Резултат**: Красиви икони в PNG и JPG формат (можете да ги конвертирате)

### Стъпка 2: Конвертиране в JPG (опционално)

Ако искате JPG формат:
- Използвайте онлайн конвертор (например cloudconvert.com)
- Или използвайте Photoshop/GIMP
- Качество: 90-95%

### Стъпка 3: Проверка на приложението

```bash
npm install
npm run dev
```

Отворете браузъра и проверете:
- ✅ Welcome screen се показва правилно
- ✅ Главното меню работи
- ✅ Можете да отваряте модулите

### Стъпка 4: База данни

Когато Supabase региона стане наличен:
- Миграцията ще се приложи автоматично
- Данните ще се съхраняват в облака
- RLS политиките ще защитават данните

**Забележка**: В момента Supabase региона е недостъпен, но това е временно.

## 📱 Публикуване

### За iOS (App Store):

1. Трябва Apple Developer акаунт ($99/година)
2. Използвайте Expo Application Services (EAS):
   ```bash
   npm install -g eas-cli
   eas build --platform ios
   eas submit --platform ios
   ```

### За Android (Google Play):

1. Трябва Google Play Developer акаунт ($25 еднократно)
2. Използвайте EAS:
   ```bash
   eas build --platform android
   eas submit --platform android
   ```

### За Web:

1. Build:
   ```bash
   npm run build
   ```

2. Deploy (безплатно):
   - Netlify: Свържете GitHub repo
   - Vercel: Автоматичен deploy
   - GitHub Pages: Статичен хостинг

## 🛠️ Технически детайли

### Структура на файловете:

```
project/
├── app/
│   ├── index.tsx              # Welcome screen
│   ├── _layout.tsx            # Root layout
│   ├── (tabs)/
│   │   ├── _layout.tsx        # Tab navigation
│   │   ├── index.tsx          # Main menu
│   │   └── history.tsx        # History screen
│   └── symptom/
│       └── [type].tsx         # Symptom tracking
├── components/
│   └── TreeOfLife.tsx         # Tree SVG component
├── lib/
│   └── supabase.ts            # Supabase client
├── types/
│   └── symptom.ts             # TypeScript types
├── assets/
│   └── images/                # Icons and images
└── scripts/
    └── generate-icons.html    # Icon generator
```

### Важни конфигурации:

- **app.json**: Име на приложението, bundle ID
- **.env**: Supabase credentials
- **package.json**: Dependencies и scripts
