# 🌳 MSASH - Multiple Sclerosis Atanas Shopov Health

Мобилно приложение за проследяване на симптоми при множествена склероза.

## 📱 Функционалности

### Начален екран (Welcome Screen)
- Красив екран с дърво на живота (символ на здравето)
- Докосване на екрана за достъп до главното меню

### Главно меню
Шест модула за проследяване на различни симптоми:

1. **Емоционално състояние** (Emotional State)
2. **Ниво на болка** (Pain Level)
3. **Нестабилност на тялото** (Body Instability)
4. **Главоболие** (Headache)
5. **Влошено зрение** (Vision Impairment)
6. **Други симптоми** (Other)

### Проследяване на симптоми
- Интуитивен интерфейс за оценка на интензитета (1-10)
- Възможност за добавяне на бележки
- Визуално кодиране с цветове:
  - 🟢 Зелено (1-3): Леко
  - 🟠 Оранжево (4-6): Средно
  - 🔴 Червено (7-10): Силно

### История
- Преглед на всички записани симптоми
- Сортировани по дата (най-нови първи)
- Детайли за всеки запис

## 🎨 Генериране на икони

### Автоматично (Препоръчва се)

За генериране на иконите е необходим Node.js с библиотека `canvas`. Това не работи в web браузъра, затова използвайте HTML метода по-долу.

### HTML Метод (Работи навсякъде!)

1. Отворете файла `scripts/generate-icons.html` във вашия уеб браузър
2. Иконите ще се генерират автоматично
3. Натиснете бутоните за изтегляне:
   - **icon.png** (1024x1024) - Основна икона на приложението
   - **favicon.png** (512x512) - Favicon за web версия
   - **splash.png** (1284x2778) - Splash screen

4. Запазете изтеглените файлове в папката `assets/images/`

### Какво съдържат иконите?

Всяка икона показва:
- ✅ Зелен градиент (символ на живот и здраве)
- 🌳 Красиво нарисувано дърво на живота
- 📝 Текст "MSASH"

## 🗄️ База данни

Приложението използва Supabase за съхранение на данни:

### Таблици:

#### `users`
- Потребителски профили
- Email, име

#### `symptom_records`
- Записи на симптоми
- Тип, интензитет, бележки
- Дата и час на записване

#### `bluetooth_devices`
- Свързани Bluetooth устройства (подготовка за бъдещи функции)

### Сигурност (RLS)
- Всеки потребител вижда само собствените си данни
- Автоматична защита чрез Row Level Security
